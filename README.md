# 黑格尔《逻辑学》通关

> 48 道选择题，按《逻辑学》自己的结构走一遍。每题答完给解释，再给一个例子。

原著被称为西方哲学最难读的一本书。难不在于词多，而在于它的每一个范畴都不是「定义」，而是**自己否定自己、再走到下一个**的运动。这个习题集就是沿着这条运动铺的：存在论 → 本质论 → 概念论。

## 结构

| 章 | 内容 | 考点 |
|---|---|---|
| 一 | 导论 · 方法 · 开端 | 逻辑学＝本体论、三环节、无前提的开端 |
| 二 | 存在论 · 质 | 有—无—变、定在、规定即否定、真无限与坏无限、自为之有 |
| 三 | 存在论 · 量 | 连续与间断、数、外延与内涵、尺度、节点线、数学的无限 |
| 四 | 本质论 · 反思 | 假象、反思、同一与差异、矛盾、根据、排中律 |
| 五 | 本质论 · 现实 | 实存、物与属性、现象、内与外、现实、实体、因果、交互作用 |
| 六 | 概念论 · 理念 | 概念三环节、判断、推论、客体性、目的论、生命、绝对理念 |

## 功能

- **每题即时反馈**：答错也讲清楚正确答案为什么对，配一个当代生活的例子。
- **术语表**：答完自动收录 48 张术语卡（术语 + 解释 + 例子）。
- **错题本**：只列错题和你当时选了什么，可一键重做。
- **进度存档**：localStorage 保存，关掉网页再回来接着做。
- **选项乱序**：以题号为种子确定性打乱，正确答案不会总在一个位置。

## 用法

纯静态，无依赖：

```bash
python3 -m http.server 8000   # 打开 http://localhost:8000
```

或者直接双击 `index.html`。

## 声明

通俗讲解，范畴译名用通行中译（贺麟/杨一之、梁志学），为便于理解做了简化。真正的原文建议从《逻辑学》的「导论」和「必须从何开始」两节读起；篇幅吃紧可先读《哲学全书》第一部分的「小逻辑」。
